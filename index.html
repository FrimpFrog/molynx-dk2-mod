How to Install

For when the mod is released. Requires your own Dungeon Keeper II and the Flame mod loader.

  1. Copy the folder. Put the MoreCreatures folder into <DK2>\flame\resources\.
  2. Put it first. Open <DK2>\flame\config.toml in Notepad and add MoreCreatures; at the very start of the alt-resources line. Flame uses the first folder on that line that has a file, so it must come first: 
    alt-resources = "MoreCreatures;your other folders"
  3. Start through Flame. Launch with the DKII-DX shortcut (the GOG launcher does not load Flame).
  4. Meet the new creatures. Start any Skirmish or My Pet Dungeon level.

About AI

We're against most uses of AI, especially where it replaces artists. Dungeon Keeper II is an old game with a small community and no funding, so this mod uses AI tools for a lot of the work. The creature concepts, design decisions and final say are ours, and everything is checked in game.
