# MegaGlest unit models on disk

Generated by `scripts/megaglest_catalog.py` from the official MegaGlest data (`techs/megapack/factions/*/units/*`, CC BY-SA 3.0). Frames and speeds are read from the `.g3d` and `.xml` files; playback fps = frames x anim-speed / 100 (die: (frames - 1) x anim-speed / 100). All of them are vertex-morph models with no skeleton, like DK2's KMF.

Only the **magic** faction is downloaded here. Your own `mg.zip` holds tilesets (trees, rocks, ...) and no factions, so the other MegaGlest factions are not catalogued yet.

## What is built into the viewer

- **Golem**: native stand/walk/attack/die/construction plus DK2 Giant-driven clips and sounds.
- **Battlemage**: native stand/walk/attack/morph/die plus DK2 Priest/Dark Elf-driven clips and sounds.
- **Behemoth**: native stand/walk/attack/die plus DK2 Giant-driven clips and sounds (the base for the custom creature).
- **wicker_behemoth** is a separate, different unit (a wicker giant) with its own models; it is not the Behemoth.
